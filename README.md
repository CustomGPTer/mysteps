# MySteps

A free step counter and health tracker for Android: steps, walks, trends, water, weight, blood pressure, heart rate, sleep, an offline UK food diary with barcode scanning, badges, journeys, reminders, widgets, a monthly report, backup and Health Connect. No adverts, no account.

- Website: https://customgpter.github.io/mysteps/
- Download: https://github.com/CustomGPTer/mysteps/releases/latest/download/MySteps.apk
- Food list (Open Database Licence): https://github.com/CustomGPTer/mysteps/releases/latest/download/MySteps-food-list.zip

This repository holds the website and the releases. The app's source code isn't published.

To report a problem, please [open an issue](https://github.com/CustomGPTer/mysteps/issues).
