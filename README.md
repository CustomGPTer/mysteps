# MySteps

MySteps is a free step counter and health diary for Android: steps all day, timed walks, fifteen famous-route journeys, 82 badges, water, weight, sleep, blood pressure, heart rate and an offline UK food diary with barcode scanning. No adverts, no account.

Website: https://customgpter.github.io/mysteps/

Download: https://github.com/CustomGPTer/mysteps/releases/latest/download/MySteps.apk
